# Security Policy

Please report suspected vulnerabilities privately through GitHub's security
advisory feature. Do not open a public issue containing credentials, personal
data, exploit details, or private logs.

Before reporting, remove tokens, API keys, personal paths, voice recordings,
memory content, and other private information. Use synthetic reproduction data
whenever possible.

Samantha requires explicit confirmation for consequential actions, but users
remain responsible for reviewing enabled tools, integrations, network access,
and filesystem permissions. Keep the API bound to loopback unless authenticated
remote access is intentionally configured.
